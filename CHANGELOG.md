# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2026-02-28

### Added

- NCC template matching for watermark validation with confidence scores.
- Batch processing for multiple input files with optional parallel execution.
- Side-by-side before/after comparison image generation.
- Verbose progress output with per-image processing summaries.

### Changed

- Improved CLI flow for single-image and batch processing modes.

## [0.1.0] - 2026-02-28

### Added

- Initial reverse alpha blending watermark removal implementation.
